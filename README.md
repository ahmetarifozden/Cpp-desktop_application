# C++ ile Dosya İşleme ve Matematiksel Operasyonlar

Bu proje, `.in` uzantılı dosyaları okuyarak içindeki veriler üzerinde matematiksel işlemler yapar ve sonuçları `.out` uzantılı dosyalara kaydeder. Proje, C++ dilinde yazılmıştır ve dosya girişi/çıkışı ile basit matematiksel işlemleri içermektedir.

## Özellikler

- **Dosya Okuma**: `.in` uzantılı dosyaları okur ve verileri işler.
- **Matematiksel İşlemler**: Dosya içeriğine göre toplama, çıkarma, çarpma veya bölme işlemleri gerçekleştirir.
- **Sonuç Kaydetme**: İşlem sonucunu `.out` uzantılı bir dosyaya yazar.
